# GameShelf — библиотека игр

Персональная библиотека видеоигр для Android от **LUNEXA**.
Коллекция, статусы прохождения, оценки, игровое время с таймером, статистика с диаграммами,
избранное и список желаемого. Работает без интернета и без регистрации.

## Возможности

- **Главная**: сводка (всего / пройдено / в процессе / желаемое), блок «Моя коллекция», недавно добавленные, достижения, активный таймер, поиск.
- **Библиотека**: сетка или список, поиск по названию, фильтры по статусу, платформе, жанру и избранному, сортировка по дате добавления, названию, оценке, году выпуска и времени.
- **6 статусов** с цветовыми индикаторами: Хочу поиграть, Играю сейчас, Пройдено, Отложено, Брошено, Перепрохожу.
- **Страница игры**: большая обложка, описание, жанр, разработчик, издатель, дата выпуска, платформы, оценка 1–10, время, даты начала и завершения, заметки, история прохождений; кнопки «Редактировать», «Удалить», «В избранное», «Статус», «Заново».
- **Игровое время**: ручной ввод часов и минут, игровые сессии с историей, таймер сессии (переживает закрытие приложения).
- **Добавление игр**: вручную с обложкой из галереи или поиск в каталоге RAWG с автозаполнением и сохранением обложки для офлайна. Повторное добавление — только с подтверждением.
- **Статистика**: кольцевая диаграмма статусов, жанры, платформы, прохождения по месяцам, время сессий, средняя оценка, топ по часам и оценкам.
- **Списки**: избранное и список желаемого (цена, дата покупки, приоритет, отметка «куплено», сортировка).
- **Профиль**: никнейм, аватар из галереи, любимые платформа и жанр, статистика.
- **Настройки**: тёмная / светлая / системная тема, 8 акцентных цветов, вид библиотеки, ключ RAWG, экспорт и импорт JSON (с обложками), автокопия перед импортом и сбросом, сброс с двойным подтверждением, «О приложении».

## Технологии

Kotlin 2.0 · Jetpack Compose · Material 3 · Room · Navigation Compose · MVVM · Coroutines/Flow · DataStore · Coil · Gradle Kotlin DSL.
minSdk 26 (Android 8.0), targetSdk 35.

## Сборка APK через GitHub Actions (без Android Studio)

1. Создайте репозиторий на GitHub (лучше приватный).
2. Загрузите туда содержимое этой папки (включая скрытую папку `.github`).
3. Откройте вкладку **Actions** → workflow «Сборка APK» запустится сам (или нажмите **Run workflow**).
4. Через 5–8 минут откройте завершённый запуск → внизу раздел **Artifacts** → скачайте `GameShelf-APK` (zip с APK внутри).

Чтобы получить APK прямо в разделе **Releases**, создайте тег: `git tag v1.0.0 && git push --tags`.

## Сборка локально

Android Studio (Ladybug или новее) → *Open* → папка проекта → *Build → Build APK(s)*.
Или в терминале: `./gradlew assembleRelease` → `app/build/outputs/apk/release/app-release.apk`.

## Установка на телефон

1. Перенесите APK на телефон (кабель, Telegram «Избранное», Google Диск).
2. Откройте файл. Если Android спросит — разрешите «Установку неизвестных приложений» для этого источника (файловый менеджер или браузер).
3. Нажмите «Установить». Play Защита может предупредить о неизвестном разработчике — выберите «Всё равно установить».
4. Перед переустановкой новой версии сделайте экспорт JSON в настройках — так данные точно не потеряются.

## Онлайн-каталог RAWG

Ключ бесплатный: зарегистрируйтесь на https://rawg.io/apidocs, скопируйте API key и вставьте его в
*Настройки → Онлайн-каталог RAWG*. Без ключа приложение полностью работает в ручном режиме.

## Ключ подписи

Без настроек APK подписывается debug-ключом сборки. Чтобы обновления ставились поверх старой версии
без переустановки, добавьте постоянный ключ в секреты репозитория (Settings → Secrets → Actions):
`GAMESHELF_KEYSTORE_BASE64`, `GAMESHELF_STORE_PASSWORD`, `GAMESHELF_KEY_ALIAS`, `GAMESHELF_KEY_PASSWORD`.
